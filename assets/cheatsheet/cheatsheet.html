Jev cheatsheet

TypeSafe AI's decision model, on one page. It doesn't write. It decides.

WHAT IT IS

  • A "System One" model. Not a chatbot.
  • You send text + questions + options.
  • You get typed answers + probabilities.
  • Plus how sure it is (confidence).
  • No training needed. Works out of the box.

THE NUMBERS

Speed70–500 ms per request
Input price$0.042 per 1M tokens
Output priceFree
Max request64K tokens · 255 options
Input typeText / JSON only

ONE CALL, THREE ANSWERS

from typesafe_sdk import Choice, Noul, Score, TypeSafeClient

client = TypeSafeClient()                       # reads TYPESAFE_API_KEY
r = client.system_one(
    state="My package arrived damaged and I want a refund.",
    questions={
        "team":   Choice(instructions="Which team should handle this",
                         criteria={"billing": "Payments", "shipping": "Delivery issues", "tech": "Bugs"}),
        "refund": Noul(instructions="The customer asks for a refund"),
        "anger":  Score(instructions="How upset the customer is", criteria=["Calm", "Annoyed", "Very angry"]),
    },
)
r.answers["team"].choice, r.answers["team"].confidence, r.answers["refund"].noul

3 QUESTION TYPES

TYPELIKERETURNS
Choicea switch.choice .confidence
Scorea rating.score .confidence
Noulan if.noul (0 to 1)

LET CONFIDENCE DECIDE

HighAct automatically
MediumAsk again or use a bigger LLM
LowSend to a human

Pick thresholds from your own labeled data.

USE IT FOR

  • Routing tickets, models, tools
  • Spam, fraud, jailbreak checks
  • Rating relevance, quality, mood
  • Filtering RAG passages
  • Fast decisions in agents and games

DON'T USE IT FOR

  • Writing text, code or summaries
  • Explaining "why"
  • Counting, dates, math (do it in code)
  • Images, audio, video (text only)
  • High-stakes calls on its own

5 GOLDEN RULES

  • Code owns the flow. Jev only judges.
  • One question = one judgment.
  • Describe every option clearly.
  • Send only what the decision needs.
  • Facts go in the state, not the model.
