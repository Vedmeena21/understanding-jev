# 🟢 Beginner projects

One Jev call per item. A few questions. Under 100 lines each.
Perfect after [lessons 00–06](../../lessons).

| Project | What it does | Jev question types |
|---|---|---|
| [Ticket router](ticket-router) | Sends support emails to the right team | Choice · Noul · Score |
| [Review ratings](review-ratings) | Turns reviews into per-feature ratings | Noul · Score |
| [Spam checker](spam-checker) | Spam, scam or phishing? | Noul · Choice |
| [Comment moderator](comment-moderator) | Keep, hide or reply to comments | Choice · Score · Noul |

## Run any of them

```bash
cd ticket-router
python main.py
```

Each one comes with sample data, so it works right away.
Then swap in your own data.
