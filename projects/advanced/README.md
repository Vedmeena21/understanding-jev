# 🔴 Advanced projects

Real-time decisions, agent internals, and training your own model.
Best after all [13 lessons](../../lessons).

| Project | What it does | What you learn |
|---|---|---|
| [Context compactor](context-compactor) | Shrinks a long agent session. Keeps what matters word for word | Fan-out over many items in one call |
| [Snake bot](snake-bot) | Jev plays Snake in your terminal | Real-time decisions. Turning a screen into words |
| [Mini-Jev](mini-jev) | Train your own tiny decision model on a laptop | How Jev (likely) works inside. No API key needed |

## Run any of them

```bash
cd snake-bot
python main.py
```

Mini-Jev needs PyTorch instead of a Jev key. See its README.
